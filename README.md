# Manufacturing Production & Defect Analytics

## Project Overview
A Big Data academic project focused on analysing manufacturing production data and identifying defects using Hadoop ecosystem technologies.

## Objective
To analyse manufacturing production records, monitor defects, and understand production-related trends using Big Data tools.

## Technologies Used
- **Hadoop** – Distributed data processing
- **HDFS** – Distributed storage
- **Hive / HiveQL** – Data querying and analysis
- **Sqoop** – Data transfer between MySQL and Hadoop
- **MySQL** – Relational database management

## Datasets
The project uses six datasets covering:
- Products
- Machines
- Employees
- Shifts
- Production
- Defects

## Key Activities
- Stored and managed data using HDFS.
- Transferred data using Sqoop.
- Created Hive tables for structured analysis.
- Performed data analysis using HiveQL queries.
- Examined production and defect-related information.
